# Changelog

## 0.1.0 - Unreleased Public Alpha

- Added the Simulated Piston block and item.
- Added automatic chain classification for single, controller, middle, and head segments.
- Added Create kinetic shaft passthrough along the piston axis.
- Added side-cog actuator speed tracking through the Create Simulated extra kinetics API.
- Added prototype Sable sublevel assembly and disassembly from the piston head.
- Added placeholder models, textures, recipe, loot table, language entries, and block tags.
- Added public alpha documentation, known issues, contributing guidance, and license audit notes.
- Clarified that users install the main Create, Create Aeronautics, and Sable packages even though bundled modules appear in the in-game mod list.

## Notes

This changelog starts during public-alpha cleanup. Earlier local prototype history may not be represented one-to-one.
